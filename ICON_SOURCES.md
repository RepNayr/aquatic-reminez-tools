# Dokumentasi Sumber Aset Ikon 3D — Aquatic Reminez Tools

Dokumen ini memuat lisensi, sumber, dan pemetaan aset ikon 3D terpusat untuk seluruh tool dan game di aplikasi **Aquatic Reminez Tools**.

## Standardisasi & Lisensi Aset
- **Gaya Visual**: 3D Modern Glossy Glassmorphism (multi-layered vector drawables dengan efek gradien linier/radial, refleksi specular bevel, dan bayangan depth).
- **Lisensi**: Free for Commercial & Distribution / Open Source / Public Domain (CC0 / Apache 2.0 / MIT Compatible, Tanpa Atribusi Wajib).
- **Arsitektur Pemetaan**: Centralized Mapping via `com.repp.aquaticremineztools.data.ToolIconRegistry` (`tool.id` -> `@drawable/ic_tool_<id>`).
- **Integritas**: 1 Tool/Game = 1 Identitas Ikon Permanen di Seluruh Layar Aplikasi (Search, Home, History, Bottom Sheets, dll).
